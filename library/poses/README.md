# Poses

One JSON file per pose; the file name must equal the `id`. A pose is a set of
feature ranges that must all hold (`PoseDef` in
`packages/protocol/src/gestures.ts`). Feature definitions, units and typical
values: **`packages/input/FEATURES.md`**. Bindings that use poses:
`library/interactions/`.

```json
{
  "id": "fist",
  "description": "Closed fist …",
  "hand": "either",                          // "left" | "right" | "either"
  "conditions": [
    { "feature": "curl.index", "min": 0.65 },
    { "feature": "thumb.out", "max": 0.8 }
  ],
  "enterMs": 80,                             // must hold this long to start (default 60)
  "exitSlack": 0.15,                         // hysteresis while active (default 0.15)
  "source": "builtin"                        // "builtin" | "recorded" | "manual"
}
```

Shipped: `pinch` (index), `pinch-middle`, `fist`, `point`, `open-palm`,
`thumbs-up`, `palm-up-open`. They are mutually exclusive except
`open-palm` ⊂ `palm-up-open` orientation-wise (an open palm-up hand is both).

Recorded poses (`source: "recorded"`) are generated by `derivePose` from a few
seconds of samples and include `stats` (mean/std per feature) - edit their
conditions freely (e.g. delete a `palm.up` condition to make one
orientation-independent). Hand-written poses should use `"source": "manual"`.
